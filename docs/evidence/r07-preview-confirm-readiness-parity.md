# R07 预览与确认 readiness 一致性

- 诊断：费用未知时，预览只判断了单次明确授权；执行层还要求价格表或单位预算策略，造成可确认预览在发送前被 `BUDGET_UNPRICED_LIMIT_REQUIRED` 拒绝，并被折叠成通用错误。
- 修正：未知费用的单次授权在无单位策略时与账本保留复用同一受控例外；硬预算仍在预览和执行前阻止。
- 预览返回安全的原因码和不含秘密的 opaque readiness binding；确认重新验证配置、凭据、能力、预算和业务输入。
- 令牌单次消费；配置、凭据或来源变化均拒绝并要求重新预览；任何已发送或不确定结果均不重试。
- 证据：`tests/v2-provider-adapter.test.ts` 使用临时 SQLite 与 Scripted provider，验证未授权零发送、授权单次发送和配置变化零追加发送。
