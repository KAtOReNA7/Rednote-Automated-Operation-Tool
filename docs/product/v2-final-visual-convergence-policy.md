# V2 最终视觉统一政策

状态：`ACCEPTED_PRODUCT_DECISION`
适用范围：V2-R04—R08
记录日期：2026-08-02

## 决定

- R04—R07 以完成本地功能闭环为优先，不设置逐任务 Figma 关卡，也不购买或调用 Figma。
- 这些任务复用已验收的 D01 壳层、tokens、组件、导航和页面职责；只增加功能必需的控件、状态、错误反馈与无障碍语义。
- 不用 ImageGen、Sites、HTML 原型、计算机控制或其他工具替代 Figma 重新设计生产界面。
- R07 完成后、R08 之前设置独立 `V2-D-FINAL` 关卡，统一审查七页、设计系统和用户体验。
- `V2-D-FINAL` 的设计及生产实现完成前，V2 不得成为默认上线入口。

## 当前视觉债务

- R02 用户反馈：周计划日期和时间选择体验仍需在最终视觉关卡统一优化；当前自由日期时间合同保持可用。
- R01 的视觉质量曾被用户判定未通过但不阻塞功能迁移；最终关卡需以成熟商业桌面产品为参照统一收口。
- R04 内容页只复用既有列表/详情结构，未处理跨页面密度、色彩、图标、卡片与间距一致性。

## 边界

本政策只决定视觉工作何时集中处理，不放宽安全、数据、IPC、审批或人工发布边界，也不授权 R05—R08 的功能实现。
